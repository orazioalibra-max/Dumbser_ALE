First-order Direct ALE (Arbitrary-Lagrangian-Eulerian) finite volume solver
for the 1D Euler equations, in MATLAB. The mesh moves with the fluid and the
solution is updated over space-time control volumes, with an ALE-Rusanov flux.

Developed for the course Hyperbolic equations and parallel computing
(Prof. E. Gaburro, UniVR), following the Direct ALE framework of Dumbser et al.
Test case: Sod shock tube / 1D Euler Riemann problems.
